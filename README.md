新的安装方法 （推荐卸载掉原有的汉化以及其余mod）

Releases 内下载最新版带有模组管理器的版本

打开mewtator文件夹内的Mewtator.exe
选择中文
需要点击自动选择游戏目录（没找到需要手动设置 mods文件夹在软件同一目录内）

旧的安装方法（无需模组加载器 但是方便快捷）

上方code 按钮的菜单内有下载zip的选项
将每个中文名字文件夹内的data文件夹

放到游戏.exe文件夹同级目录
